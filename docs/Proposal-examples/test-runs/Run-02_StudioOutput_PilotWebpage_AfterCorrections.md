## The honest remaining question for Build night

The pricing rule works on pilot web builds because I handed it the answer. Nobody has tested whether it generalizes — what happens when an inquiry arrives that doesn't match P-01 through P-04? A photography-led job, a video project, a retainer-only client, a $6,000 scope. The Studio has no anchor for those and will either flag **[your call]** correctly or quietly reach for the nearest wrong number.

**Build night test:** run one deliberately off-pattern inquiry and check whether it flags [your call] instead of guessing. That is the real measure of whether the pricing logic holds.
