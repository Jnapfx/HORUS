## Stage 2 — Draft

### Project summary
Pilot web presence for a regional workforce initiative: a single hub connecting employers, students, and early-career talent to hands-on opportunities. Built in the client's existing WordPress environment, with intake forms, an opportunity listings section, lightweight automation, and submissions routed to Google Drive.

### Scope of work
- **Discovery & planning** — review goals, audit existing WordPress environment, define page structure and user flow *(pattern from P-04)*
- **Design & development** — responsive pilot page, brand-guide-aligned, clear navigation *(P-04)*
- **Engagement features** — opportunity listings, intake/contact forms, submissions to Google Drive, CTAs
- **Lightweight automation** — form routing and notification workflows; no external CRM/API sync *(scoped as a limited version of the P-03 automation pattern)*
- **Technical** — basic SEO, cross-device testing, performance/usability QA
- **Launch support** — final QA, launch assistance, minor post-launch adjustments

### Exclusions
Plugin/hosting/licensing costs · content writing (client-supplied) · external CRM or database integration · accessibility remediation beyond basic standards · photography.

### Timeline
4–6 weeks from kickoff and receipt of content, brand guide, and platform access. Aligns with a late-summer / early-fall 2026 target. *(range from P-04's phased structure, extended for the listings + automation scope)*
