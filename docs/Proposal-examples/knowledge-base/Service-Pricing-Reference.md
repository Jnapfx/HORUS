## Pricing structure rules (added after Week 4 comparison run)
- **Under ~$2,500, fixed scope → one flat number.** Pilot pages, single-page builds, refreshes. Do not tier. (Real-world anchor: the $2,000 pilot build in P-02 was quoted flat and won.)
- **Tiers are for brand/identity packages only**, where the client is choosing a level of investment (P-01: $2,500 core vs. $3,800 expanded).
- **Small pilot web build baseline: $2,000 flat** (P-02) — this is the anchor for pilot-scale work, not the P-04 rebuild range ($950–$1,400), which assumes a simpler site with no listings or automation.
- **The standard on-page AI FAQ assistant is included in every web build.** Never quote it as an add-on. Advanced customization only is separately priced (from $500).
- **Always attach the full optional-services rate card**, not a subset.
