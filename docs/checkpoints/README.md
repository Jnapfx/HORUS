# Checkpoints

A checkpoint proves that a phase is complete and reproducible. It is more than a progress note.

## Naming convention

`YYYY-MM-DD_milestone-name.md`

Example: `2026-08-20_primary-workflow-validated.md`

## When to create one

- When completing a roadmap phase.
- Before a significant architectural change.
- Before user testing or deployment.
- When a stable version exists that may need to be restored later.

Use [`../templates/CHECKPOINT_TEMPLATE.md`](../templates/CHECKPOINT_TEMPLATE.md) as the starting point.
