# Historical Archive

This directory stores earlier material that may provide context but **does not represent the current state of HORUS V1**.

## Rules

- Do not copy the entire previous repository.
- Import only documents, screenshots, or excerpts with clear value.
- Record the source, approximate date, and reason for retention.
- Mark any assumption that has not yet been validated.
- Move an idea into the current project only through an explicit decision.

## Recommended header

```text
Source:
Approximate date:
Reason for retention:
Status: historical / not approved
```
